# TradingLab Backup — Pagine informative OAuth

Repository **pubblico esclusivamente per pagine informative** dell'app OAuth personale TradingLab Backup.

Contiene `index.html`, `privacy.html` e `style.css`. Sono pagine statiche, senza JavaScript, moduli, tracciamento o credenziali.

**Non caricare in questo repository** codice operativo TradingLab, configurazioni rclone, token OAuth, dati di trading, log, manifest o backup.

## Attivazione GitHub Pages

Repository → **Settings → Pages** → **Build and deployment** → **Deploy from a branch** → branch `main`, directory `/ (root)` → **Save**.

Dopo l'attivazione controllare:
- https://marcoan83.github.io/tradinglab-backup-oauth-pages/
- https://marcoan83.github.io/tradinglab-backup-oauth-pages/privacy.html

## Google OAuth

Le pagine sono pubbliche; l'app TradingLab e i dati di Drive rimangono privati. L'uso di `github.io` non garantisce la verifica del dominio/brand da parte di Google. Se Google richiede la verifica della proprietà, servirà valutare un dominio controllato dal proprietario.

Queste pagine non modificano token OAuth, configurazioni VPS, schedulazioni o strategie TradingLab.
